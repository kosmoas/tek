# TEK - Tesla Fleet API 

## About

TEK is a project I started to learn more about APIs, OAuth, cloud services, and backend development while working with the Tesla Fleet API.

The goal is to build a web application that can connect to Tesla vehicles and display information such as battery level, charging status, vehicle state, and other telemetry. I also use this project to experiment with authentication, API integrations, and self-hosted development environments.

This project has been one of my main ways of learning how real-world APIs work outside of the classroom.

## Features

* Tesla Fleet API integration
* OAuth 2.0 authentication flow
* Vehicle information retrieval
* Battery and charging data
* Vehicle status monitoring
* REST API endpoints
* TypeScript and Express backend

## Technologies Used

* TypeScript
* Node.js
* Express
* Tesla Fleet API
* OAuth 2.0
* Axios
* Docker
* Git

## Why I Built It

I wanted a project that would push me beyond basic programming assignments and teach me skills that are actually used in industry. Since I own a Tesla and enjoy working with technology, building something around the Tesla Fleet API felt like a good challenge.

Along the way I've learned about authentication, API security, debugging, deployment, environment variables, and working with external services.
